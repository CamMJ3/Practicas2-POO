## 💻 Descripción del proyecto

Este repositorio contiene cinco ejercicios desarrollados en C++ con el objetivo de practicar los principales conceptos de la **Programación Orientada a Objetos (POO)** y el uso de colecciones de la biblioteca estándar de C++ (STL).

## 📂 Contenido del repositorio

### 1. 🚘 Jerarquía simple
Implementación de una clase base `Vehiculo` y dos clases derivadas, `Auto` y `Motocicleta`, utilizando herencia y sobrescritura de métodos.

### 2. 🔄 Polimorfismo en acción
Creación de una colección de objetos de diferentes tipos derivados de `Vehiculo`, demostrando el comportamiento del polimorfismo mediante el método `mostrarInfo()`.

### 3. ➕ Sobrecarga de operadores
Implementación de la clase `Fraccion`, con sobrecarga de los operadores `+` y `==` para sumar fracciones y comparar su equivalencia.

### 4. 🧮 Sobrecarga de métodos
Desarrollo de la clase `Calculadora`, con tres versiones del método `sumar()` para trabajar con dos enteros, tres enteros y dos números decimales.

### 5. 📚 Colección con iterador
Uso de un contenedor `vector` para almacenar diferentes vehículos y recorrerlos mediante un iterador de C++.

## 🛠️ Tecnologías utilizadas

- **Lenguaje:** C++
- **Biblioteca estándar:** STL
- **Contenedores:** `vector`
- **Conceptos:** Herencia, polimorfismo, sobrescritura de métodos, sobrecarga de operadores, sobrecarga de métodos e iteradores.
- **Compilador:** GCC (g++)

## ▶️ Compilación y ejecución

Para compilar y ejecutar cualquiera de los ejercicios desde una terminal de Windows con GCC instalado, utiliza los siguientes comandos como ejemplo:

```powershell
g++ ejercicio1.cpp -o ejercicio1
.\ejercicio1
```

Cada ejercicio debe compilarse y ejecutarse por separado, ya que cuenta con su propia función `main()`.
